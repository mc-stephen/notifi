## What is Notifi?

Notifi is a notification infrastructure platform that lets you build, manage, and scale notification workflows across multiple channels — email, SMS, push, webhooks, and more.

## Key Features

- **Multi-channel delivery** — Send notifications through email, SMS, push, and webhooks from a single API.
- **Template management** — Create and manage message templates with dynamic variables.
- **Event-driven** — Trigger notifications based on events in your system.
- **Delivery guarantees** — At-least-once delivery with automatic retries.
- **Observability** — Full delivery logs, metrics, and tracing.
