title: Notifications
description: Send, list, and retrieve notifications via the REST API.
---

## Send a Notification

<PostMethod />

```http
POST /notifications
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "channel": "email",
  "to": "user@example.com",
  "template": "welcome-email",
  "data": {
    "name": "Alice"
  }
}
```

### Response

```json
{
  "id": "notif_abc123",
  "status": "queued",
  "channel": "email",
  "created_at": "2026-07-29T12:00:00Z"
}
```

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `channel` | string | ✅ | email, sms, push, or webhook |
| `to` | string | ✅ | Recipient address or device token |
| `template` | string | ❌ | Template ID for the message |
| `data` | object | ❌ | Template variable values |

---

## List Notifications

<GetMethod />

```http
GET /notifications?limit=10&offset=0
Authorization: Bearer YOUR_API_KEY
```

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | integer | 10 | Number of results per page |
| `offset` | integer | 0 | Pagination offset |
| `status` | string | — | Filter: queued, delivered, failed |

### Response

```json
{
  "data": [
    {
      "id": "notif_abc123",
      "status": "delivered",
      "channel": "email",
      "created_at": "2026-07-29T12:00:00Z"
    }
  ],
  "pagination": {
    "limit": 10,
    "offset": 0,
    "total": 42
  }
}
```

## Get a Notification

<GetMethod />

```http
GET /notifications/{id}
Authorization: Bearer YOUR_API_KEY
```

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Notification ID |

### Response

```json
{
  "id": "notif_abc123",
  "status": "delivered",
  "channel": "email",
  "template": "welcome-email",
  "to": "user@example.com",
  "data": { "name": "Alice" },
  "created_at": "2026-07-29T12:00:00Z",
  "updated_at": "2026-07-29T12:00:05Z"
}
```
