title: Channels
description: Delivery channels supported by Notifi.
---

Notifi supports sending notifications through multiple delivery channels. Each channel has its own configuration and capabilities.

## Available Channels

| Channel | Use Case | Status |
|---------|----------|--------|
| Email | Transactional and marketing emails | ✅ GA |
| SMS | Text message notifications | ✅ GA |
| Push | Mobile push notifications (FCM, APNs) | ✅ GA |
| Web Push | Browser push notifications | ✅ GA |
| Webhook | Server-to-server delivery | ✅ GA |
| RCS | Rich messaging | 🚧 Beta |
| Linux Notifications | Desktop notifications | 🚧 Beta |
| macOS Notifications | Desktop notifications | 🚧 Beta |
