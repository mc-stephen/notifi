The trick is this:

> **Never ask an AI to build a landing page.**
>
> **Ask it to design a premium SaaS marketing experience.**

Those are two completely different prompts.

---

## Before I give you the prompt...

I want to tell you something that I think will completely change how you approach this company.

You are **NOT** building:

* a notification API
* a Rust server
* a dashboard

You're building a **brand**.

When someone visits

```
yourdomain.com
```

they should immediately think

> "Damn... these guys look serious."

before they've read a single sentence.

That's exactly what Stripe, Vercel, Linear, Clerk, Cloudflare and Resend achieve.

They sell confidence before they sell features.

---

# My Design Philosophy

If I were designing your landing page, I would optimize for four things.

```
WOW

↓

Trust

↓

Understanding

↓

Conversion
```

In exactly that order.

People don't read first.

They look.

Then they scroll.

Then they trust.

Then they sign up.

---

# Here's another thing I do...

I don't ask AI to create sections.

I tell it **what emotion every section should create.**

Example

```
Hero

Emotion:
Curiosity

Supported Channels

Emotion:
Capability

Architecture

Emotion:
Technical Confidence

Analytics

Emotion:
Enterprise Readiness

Testimonials

Emotion:
Social Proof

Pricing

Emotion:
Low Risk

CTA

Emotion:
Excitement
```

This dramatically improves designs.

---

# Another trick...

Never say

```
Modern UI
```

That's meaningless.

Instead say

```
The website should feel like it was designed by a world-class product design team with the same attention to detail, spacing, motion, typography, and visual hierarchy found in premium developer platforms.

Every section should be portfolio-worthy.

Every scroll should reveal something memorable.

The page should feel expensive.
```

That changes everything.
