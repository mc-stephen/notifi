title: Getting Started
description: Get up and running with Notifi in minutes.
---

Follow this guide to send your first notification. The entire process takes less than 10 minutes.

```text
1. Create an Account
2. Create an Organization
3. Create a Project
4. Generate an API Key
5. Install the SDK
6. Send Your First Notification
```

## Prerequisites

- A modern web browser
- A terminal for running API requests
- Node.js 18+ (for the JavaScript SDK)
