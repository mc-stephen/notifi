Security is built into every layer of the Notifi platform.

## Key Areas

- **Authentication** — API keys, OAuth 2.0, and JWT-based session management
- **Encryption** — Data encrypted at rest (AES-256) and in transit (TLS 1.3)
- **Compliance** — SOC 2 Type II, GDPR, and HIPAA compliance
