# Notifi Typography

## Font Stack

| Usage   | Font             | Fallback                  |
|---------|------------------|---------------------------|
| Display | Geist            | `system-ui, sans-serif`   |
| Monospace| Geist Mono      | `ui-monospace, monospace` |

## Weights

| Weight  | Name     | Usage                        |
|---------|----------|------------------------------|
| 400     | Regular  | Body text                    |
| 500     | Medium   | Navigation, buttons          |
| 600     | Semibold | Subheadings, emphasis        |
| 700     | Bold     | Headings, display text       |

## Scale

| Level        | Size  | Weight | Line Height |
|--------------|-------|--------|-------------|
| H1           | 36px  | 700    | 1.1         |
| H2           | 30px  | 700    | 1.2         |
| H3           | 24px  | 600    | 1.3         |
| H4           | 20px  | 600    | 1.3         |
| Body         | 16px  | 400    | 1.6         |
| Body Small   | 14px  | 400    | 1.5         |
| Caption      | 12px  | 400    | 1.4         |
| Code         | 14px  | 400    | 1.5         |

## Usage

- Headings use Geist Semibold/Bold with tighter tracking
- Body text uses Geist Regular at 16px for readability
- Code blocks and inline code use Geist Mono
- Button labels use Geist Medium at 14px
