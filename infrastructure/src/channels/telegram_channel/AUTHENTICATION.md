# Telegram Channel Authentication

To enable Telegram notifications, you need to configure your brand's bot credentials.

## Requirements
- **Bot Token**: Your Telegram Bot API token.

## How to get your Bot Token
1. Open Telegram and search for **@BotFather**.
2. Click **Start** or type `/newbot`.
3. Follow the instructions to name your bot and provide a unique username (must end in `bot`).
4. Once created, **@BotFather** will provide your API Token.
5. Use this token in your configuration file (`configs/{brand}/telegram/config.json`).
